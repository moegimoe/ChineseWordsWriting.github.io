# 中文単語帳 ChineseTrainer

大学の中国語授業で配布される単語リストを効率よく暗記するための、スマホ・PC対応の単語テストアプリです。
フレームワーク不要（Vanilla JS / ES Modules）、ビルド不要、GitHub Pagesにそのまま公開できます。

## 使い方（毎回の流れ）

1. 授業資料の単語一覧をコピー
2. アプリの「＋」から取り込み画面を開き、貼り付け
3. 「読み込み」→ 内容を確認して「単語帳に保存」
4. ホーム画面でその課（または「すべての課」）をタップ →「テスト開始」

## 対応する貼り付け形式

**形式A: 空行区切り（中国語→改行→意味）**
```
叫
〜という

专业
専攻
```

**形式B: パイプ区切り（ピンイン指定あり）**
```
学习|xuéxí|学習
```

**形式C: 空行なしの交互形式**
```
叫
〜という
专业
専攻
```

3つとも自動判定されます。CSVへの変換は不要です。

## ピンインの自動取得について

`pinyin-pro` という外部ライブラリ（CDN経由）を読み込んで、貼り付け時に自動でピンインを付与します。
オフライン時や初回オフラインアクセス時など、ライブラリを読み込めない場合はピンインが空欄になりますが、
その場合も形式Bの `漢字|ピンイン|意味` で手動指定すれば問題なく動作します。
ピンインが空欄の単語は「① ピンイン→中国語」モードでは出題しにくくなるだけで、
他の3モード（音声／意味／中国語→意味）には影響しません。

## 出題モード

1. ピンイン → 中国語（🔊で発音確認、手書き/通常キーボードで入力）
2. 音声 → 中国語（自動で読み上げ、文字は非表示）
3. 意味 → 中国語
4. 中国語 → 意味

## 出題方式

- シャッフル / 順番通り / 苦手優先 / 間違えた問題だけ / 復習（Ankiライク間隔反復）

## 学習データ

すべて端末内の LocalStorage に保存されます（外部送信なし）。
設定画面から JSON 形式でバックアップ（書き出し・復元）が可能です。

## GitHub Pages への公開手順

1. このフォルダの中身をリポジトリの直下（または `/docs` フォルダ）にそのままコミット
2. GitHub の Settings → Pages で公開するブランチ・フォルダを指定
3. 発行されたURLにアクセス → スマホなら「ホーム画面に追加」でPWAとしてインストール可能

## ディレクトリ構成

```
ChineseTrainer/
  index.html        画面構造
  style.css         スタイル（ダークモード対応）
  app.js            画面遷移・イベント配線（エントリーポイント）
  parser.js         貼り付けテキストの解析
  quiz.js           出題キュー生成・正誤判定
  speech.js         SpeechSynthesis（中国語読み上げ）ラッパー
  storage.js        LocalStorage 読み書き
  review.js         間隔反復（SRS）ロジック
  manifest.json     PWAマニフェスト
  service-worker.js オフラインキャッシュ
  assets/icons/     アプリアイコン
```

## 手書き入力について

ブラウザ側での手書き文字認識は行っていません。スマホの中国語手書きキーボード（iOS/Androidの
標準入力方式）を有効にした状態で、通常の `<input>` へ入力する前提の設計です。
